# Devpost description (under 250 words)

**Hushroom** is a calm, cosy focus room for students, in a single website with no signup, no backend and no tracking.

Studying online usually means juggling a timer tab, a noise video full of ads, and a to-do app. Hushroom puts them in one quiet place that feels nice to be in.

**Key features**
- **Pomodoro timer:** accurate even in a background tab (it uses timestamps, not tick counting), with a live tab-title countdown and a soft chime.
- **Ambient mixer:** rain, wind, fireplace, café murmur, brown noise and a lo-fi pad. Every sound is synthesised live with the Web Audio API. There are no audio files, so it loads instantly and works offline.
- **Living window scene:** drawn on canvas. The sky follows Dawn, Day, Dusk or Night (or your local time), and the scene reacts to the mix. Rain streaks and droplets, a flickering fire glow, and swaying trees all respond to the sounds you choose.
- **Tasks and stats:** pick one current task, track sessions per task, and see streaks, a weekly chart, a 12-week heatmap and badges.
- **Focus mode, shortcuts, installable PWA**, plus JSON export and import of your data.

**Built with** plain HTML, CSS and vanilla JavaScript. There are zero runtime dependencies. All data stays in your browser. Built with accessibility in mind: keyboard control, WCAG AA contrast, reduced-motion support.
